# 技能设计中的说服原则

## 概述

大型语言模型对人类的说服原则同样敏感。理解这一心理机制有助于你设计更有效的技能——不是为了操纵，而是确保关键实践即使在压力下也能被遵循。

**研究基础：** Meincke 等人（2025）在 N=28,000 个 AI 对话中测试了 7 条说服原则。说服技巧使遵从率提升了一倍以上（33% → 72%，p < .001）。

## 七项原则

### 1. 权威
**定义：** 对专业知识、资质或官方来源的服从。

**在技能中的运作方式：**
- 命令式语言："你必须"、"绝不"、"始终"
- 不可协商的表述："无例外"
- 消除决策疲劳和合理化借口

**使用时机：**
- 纪律强化型技能（TDD、验证要求）
- 安全关键实践
- 既定最佳实践

**示例：**
```markdown
✅ 先写代码再写测试？删掉，重新开始。无例外。
❌ 在可行的情况下考虑先写测试。
```

### 2. 承诺一致性
**定义：** 与先前的行动、声明或公开表态保持一致。

**在技能中的运作方式：**
- 要求声明："宣布技能使用"
- 强制明确选择："选择 A、B 或 C"
- 使用追踪：通过 TodoWrite 管理检查清单

**使用时机：**
- 确保技能被实际遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ 当你找到一项技能时，必须声明："我正在使用 [技能名称]"
❌ 可以考虑让你的人类伙伴知道你正在使用哪个技能。
```

### 3. 稀缺性
**定义：** 由时间限制或有限可用性产生的紧迫感。

**在技能中的运作方式：**
- 限时要求："在进行之前"
- 顺序依赖："紧接在 X 之后"
- 防止拖延

**使用时机：**
- 即时验证要求
- 时间敏感型工作流
- 防止"我稍后再做"

**示例：**
```markdown
✅ 完成任务后，立即请求代码审查再继续下一步。
❌ 你可以方便的时候再审查代码。
```

### 4. 社会认同
**定义：** 遵从他人的做法或被视为常规的行为。

**在技能中的运作方式：**
- 通用模式："每次"、"始终"
- 失败模式："没有 Y 的 X = 失败"
- 建立规范

**使用时机：**
- 记录通用实践
- 警告常见失败
- 强化标准

**示例：**
```markdown
✅ 没有 TodoWrite 追踪的检查清单 = 步骤会被跳过。每次都如此。
❌ 有些人觉得 TodoWrite 对检查清单有帮助。
```

### 5. 团结感
**定义：** 共享身份、"我们感"、群体归属。

**在技能中的运作方式：**
- 协作语言："我们的代码库"、"我们是同事"
- 共同目标："我们都追求质量"

**使用时机：**
- 协作工作流
- 建立团队文化
- 非等级制实践

**示例：**
```markdown
✅ 我们是并肩工作的同事。我需要你真诚的技术判断。
❌ 你可能应该告诉我是否错了。
```

### 6. 互惠
**定义：** 回报所受恩惠的义务感。

**运作方式：**
- 谨慎使用——可能让人感觉被操纵
- 技能中很少需要

**应避免的时机：**
- 几乎始终如此（其他原则更有效）

### 7. 喜好
**定义：** 倾向于与喜欢的人合作。

**运作方式：**
- **不要用于强制遵从**
- 与诚实反馈文化相冲突
- 会产生谄媚行为

**应避免的时机：**
- 纪律强化中始终避免

## 按技能类型的原则组合

| 技能类型 | 使用 | 避免 |
|------------|-----|-------|
| 纪律强化型 | 权威 + 承诺一致性 + 社会认同 | 喜好、互惠 |
| 指导/技术型 | 适度权威 + 团结感 | 过度权威 |
| 协作型 | 团结感 + 承诺一致性 | 权威、喜好 |
| 参考型 | 仅需清晰性 | 所有说服技巧 |

## 为何有效：心理学原理

**明确规则减少合理化：**
- "你必须"消除决策疲劳
- 绝对性语言消除"这是例外吗？"的疑问
- 明确的反合理化机制堵住特定漏洞

**执行意图创造自动行为：**
- 清晰触发器 + 必要行动 = 自动执行
- "当 X 发生时，做 Y"比"通常做 Y"更有效
- 降低遵从的认知负荷

**大型语言模型具有类人性：**
- 训练数据包含这些模式的人类文本
- 权威语言在训练数据中先于遵从出现
- 承诺序列（声明 → 行动）被频繁建模
- 社会认同模式（每个人都做 X）建立规范

## 伦理使用

**正当用途：**
- 确保关键实践被遵循
- 创建有效的文档
- 预防可预见的失败

**不正当用途：**
- 为个人利益进行操纵
- 制造虚假紧迫感
- 基于愧疚的强制遵从

**检验标准：** 如果用户完全理解这项技术，它是否服务于用户的真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 说服七项原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 在 N=28,000 个大型语言模型对话中测试了 7 条原则
- 使用说服技巧后遵从率从 33% 提升至 72%
- 权威、承诺一致性、稀缺性效果最显著
- 验证了大型语言模型的类人性模型

## 快速参考

设计技能时，请思考：

1. **这是什么类型的技能？**（纪律型 vs. 指导型 vs. 参考型）
2. **我想改变什么行为？**
3. **适用哪些原则？**（纪律型通常用权威 + 承诺一致性）
4. **是否组合过多？**（不要七项全用）
5. **这样做合乎伦理吗？**（是否服务于用户的真实利益？）
