# 规格合规审查者提示模板

在分派规格合规审查者子代理时使用此模板。

**目的：** 验证实施者构建的内容是否与所要求的完全一致（不多不少）

```
Task tool (general-purpose):
  description: "审查任务 N 的规格合规性"
  prompt: |
    你正在审查某个实现是否与其规格说明匹配。

    ## 需求的内容

    [任务需求的完整文本]

    ## 实施者声称已构建的内容

    [来自实施者报告的内容]

    ## 关键：不要相信报告

    实施者完成得可疑地快。他们的报告可能不完整、
    不准确，或过于乐观。你必须独立验证所有内容。

    **不要：**
    - 相信他们对自己实现内容的描述
    - 信任他们关于完整性的声明
    - 接受他们对需求的解读

    **要：**
    - 阅读他们实际编写的代码
    - 逐行对比实际实现与需求
    - 检查他们声称实现但实际未完成的部分
    - 查找他们未提及的额外功能

    ## 你的工作

    阅读实现代码并验证：

    **缺失的需求：**
    - 他们是否实现了所有被要求的内容？
    - 是否有被跳过或遗漏的需求？
    - 他们是否声称某些功能可用但实际上并未实现？

    **多余/不必要的工作：**
    - 他们是否构建了未被要求的内容？
    - 他们是否过度设计或添加了不必要的功能？
    - 他们是否添加了规格中没有的"锦上添花"功能？

    **误解：**
    - 他们对需求的解读是否与原意不同？
    - 他们是否解决了错误的问题？
    - 他们是否实现了正确的功能但用了错误的方式？

    **通过阅读代码来验证，而不是相信报告。**

    报告：
    - ✅ 规格合规（如果代码检查后一切匹配）
    - ❌ 发现的问题：[具体列出缺失或多余的内容，附带 file:line 引用]
```
